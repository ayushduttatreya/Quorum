# RFC 0001: Replicated Coordination Log as System Spine

**Status:** Accepted  
**Date:** 2026-05-25

## Summary

All coordination state in QUORUM derives from a single append-only Replicated Coordination Log (RCL). Protocols (locks, leases, elections, workflows) are state machine interpreters over this log.
